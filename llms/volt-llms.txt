# Volt

> Volt is a desktop app (Mac, Windows, Chrome) that supercharges WhatsApp for professionals and sales teams — voice-note transcription and summaries, message scheduling, keyboard-first navigation, workspaces, and personalized broadcasts. Message content stays under WhatsApp's end-to-end encryption and never passes through Volt's servers. Volt exposes an authenticated remote MCP server so AI agents can access WhatsApp contacts, chats, messages, groups, and lists.

## Agent / MCP access
- [MCP overview](https://voltchat.com/docs/mcp/overview): Connect AI models and agents to Volt.
- [MCP setup](https://voltchat.com/docs/mcp/setup-instructions): OAuth custom connector or Bearer API key via mcp-remote.
- [MCP FAQ](https://voltchat.com/docs/mcp/faq)
- Remote MCP endpoint: https://mcp.voltchat.com/mcp (HTTP transport)
- Tools: send-message, search-contact, list-chats, get-chat-messages, create-group, add-participants-to-group, remove-participants-from-group, promote-participants-to-admins, demote-participants-from-admins, get-own-identity, add-chat-to-lists, remove-chat-from-lists, get-chat-lists, get-chats-in-list, set-chat-read-state
